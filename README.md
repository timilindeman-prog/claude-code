# Minimal Next.js App (TypeScript)

This project is a minimal Next.js app using the **App Router**.

## Requirements

- Node.js 18.17+ (Node.js 20+ recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Included UI

At `/`, the app has:

- a textarea labeled **"Describe the app you want"**
- a button labeled **"Generate"**
- an empty bordered output area below for future results
